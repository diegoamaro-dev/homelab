What is AMAROLAB?

AMAROLAB is my long-term personal homelab.

It has evolved into a complete self-hosted infrastructure where I design, build, validate and document everything required to operate a modern AI ecosystem.

Instead of deploying isolated services, every component is engineered to become part of a single coherent platform focused on:

🧠 Local Artificial Intelligence
🏠 Home Automation
📚 Knowledge Systems
⚙️ Infrastructure Engineering
🔒 Digital Sovereignty

This repository contains both the infrastructure and the complete engineering documentation behind it.

Reality always wins.

Documentation First

Security Before Convenience
No Secrets In Git
Every Change Is Traceable
Why this project?

Most homelabs are collections of services.

AMAROLAB is an engineering platform.

Every deployment is treated as production.

Every architectural decision is documented.

Every failure becomes a lesson.

Every improvement is traceable.

The objective is not simply to build a homelab.

The objective is to become a better infrastructure engineer by building one.
